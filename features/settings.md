# Feature: Settings Reference

## Overview
System-wide configuration for hardware, tax, and business logic.

## Configuration Areas
- **Hardware**: Printer IP/Bluetooth pairing, Cash drawer pulse settings.
- **Tax & Rounding**: SST activation, Service charge percentages.
- **Sync**: Master/Slave terminal roles, server IP configuration.
- **Workspace**: Business name, address, and BRN for receipt headers.
