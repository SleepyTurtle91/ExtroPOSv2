# Feature: Authentication Reference

## Overview
Secure login and permission-based access control.

## Components
- **PIN Login**: Fast access for cashiers.
- **Biometric**: Optional manager override via fingerprint.
- **Role Enforcement**: UI elements are hidden or disabled based on the active user's permissions.

## Session Management
- **Shift Linkage**: Authenticated users are linked to their active shift for accountability.
